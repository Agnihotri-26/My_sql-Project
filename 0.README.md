# 🎓 Student Management System — MySQL

A complete **Student Management System** built with MySQL, covering everything from basic CRUD operations to advanced SQL concepts like joins, subqueries, stored procedures, and a student login system.

---

## 📌 Project Overview

This project simulates a real-world school/college database system. It is divided into two levels:

- **Level 1** — Core tables (Students, Courses, Enrollment)
- **Level 2** — Advanced tables (Attendance, Fees, Exams, Login System, Timestamps)

---

## 🗂️ Database Schema

### Level 1 — Core Tables

| Table | Description |
|---|---|
| `students` | Stores student personal information |
| `courses` | Stores available courses |
| `enrollment` | Maps students to their enrolled courses |

### Level 2 — Advanced Tables

| Table | Description |
|---|---|
| `attendance` | Tracks student attendance per course |
| `fees` | Manages fee payment records |
| `exam` | Stores exam marks and results |
| `student_login` | Student login credentials system |

> All Level 2 tables include `created_at` timestamps for record tracking.

## 🧱 Table Structure

### `students`
```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    email VARCHAR(100) UNIQUE,
    phone VARCHAR(15),
    address TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### `courses`
```sql
CREATE TABLE courses (
    course_id INT PRIMARY KEY AUTO_INCREMENT,
    course_name VARCHAR(100),
    duration VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### `enrollment`
```sql
CREATE TABLE enrollment (
    enrollment_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    course_id INT,
    enrollment_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
```

### `attendance`
```sql
CREATE TABLE attendance (
    attendance_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    course_id INT,
    date DATE,
    status ENUM('Present', 'Absent'),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
```

### `fees`
```sql
CREATE TABLE fees (
    fee_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    amount DECIMAL(10,2),
    payment_date DATE,
    status ENUM('Paid', 'Pending'),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id)
);
```

### `exam`
```sql
CREATE TABLE exam (
    exam_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    course_id INT,
    marks INT,
    grade VARCHAR(5),
    exam_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
```

### `student_login`
```sql
CREATE TABLE student_login (
    login_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT UNIQUE,
    username VARCHAR(50) UNIQUE,
    password VARCHAR(255),
    last_login TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id)
);
```

## 🔍 SQL Queries Covered

### ✅ Basic Queries
- `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- Filtering with `WHERE`, `AND`, `OR`, `NOT`
- Sorting with `ORDER BY`
- Limiting results with `LIMIT`

### ✅ Joins
- `INNER JOIN` — Students with their enrolled courses
- `LEFT JOIN` — All students, including those not enrolled
- `RIGHT JOIN` — All courses, including those with no students
- Multi-table joins across students, courses, enrollment, and exam tables

### ✅ Subqueries
- Students who scored above the average marks
- Students with unpaid fees
- Courses with the highest enrollment count

### ✅ Aggregate Functions
- `COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()`
- `GROUP BY` and `HAVING`

### ✅ Advanced Concepts
- `TIMESTAMP` with `DEFAULT CURRENT_TIMESTAMP`
- `ENUM` for status fields
- `FOREIGN KEY` constraints
- Student login system with username/password

## ⚙️ How to Run

1. **Clone this repository**
   ```bash
   git clone https://github.com/your-username/student-management-mysql.git
   cd student-management-mysql
   ```

2. **Open MySQL** (via terminal or MySQL Workbench)

3. **Create the database**
   ```sql
   CREATE DATABASE student_management;
   USE student_management;
   ```

4. **Import the SQL file**
   ```bash
   mysql -u root -p student_management < student_management.sql
   ```

5. **Run queries** from the `queries/` folder or write your own!

Symbols on the relationship lines:

|| = exactly one (mandatory)
o{ = zero or many (optional many)
||--o{ = one-to-many relationship

Relationships shown:

students → enrollment — one student can enroll in many courses
courses → enrollment — one course can have many students
students → attendance — one student has many attendance records
courses → attendance — one course has many attendance records
students → fees — one student has many fee records
students → exam — one student appears in many exams
courses → exam — one course has many exam records
students → student_login — one student has exactly one login account
